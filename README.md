# Tarango Hasan — Things I've Built

Portfolio and technical archive of **Tarango Hasan**, a Class 8 student at Rangpur Zilla School, Bangladesh. A dark, minimalist showcase of real websites, web applications, browser extensions and experiments.

**Live:** `tarangohasan` · `eight.selfstudy.xyz` · `annotate.selfstudy.xyz`

## Stack
React + TypeScript + Vite (SPA, no Next.js) · React Router · Custom cursor + space background canvas · Dark-only (#0a0a0c) + emerald (#10b981)

## Routes
`/` · `/work` · `/work/:slug` · `/about` · `/process` · `/experiments`

## Develop
```bash
npm install
npm run dev     # http://localhost:5173
npm run build
npm run preview
```
